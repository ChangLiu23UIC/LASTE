# Photobleaching Proteomics — Zebrafish Olfactory Epithelium and Spinal Cord

Label-free proteomics comparing photobleached (PB) and non-photobleached (NPB) cell
fractions in *Danio rerio*, in two tissues:

| Tissue | Samples | Data |
|---|---|---|
| **OE** — olfactory epithelium | 17 runs, two batches (`OE1`, `OE2`) | `data/oe_proteomics/` |
| **SC** — spinal cord | 4 runs, one batch, no replicates | `data/spinal_cord_proteomics/` |

Proteins are quantified as NSAF (normalised spectral abundance factor) from FragPipe
spectral counts, restricted to *Danio rerio* entries. The pipeline then produces sample
correlation, a UMAP embedding with Leiden grouping, clustered heatmaps, and GO enrichment.

## Quickstart

```bash
python -m venv .venv
.venv/Scripts/activate          # Windows;  source .venv/bin/activate on Unix
pip install -r requirements.txt

python src/oe_analysis.py       # -> results/oe/{figures,tables}/
python src/spine_analysis.py    # -> results/spinal_cord/{figures,tables}/
```

Two commands regenerate every committed figure and table. Both scripts resolve their paths
through `src/paths.py`, so they run from any working directory.

## Sample naming

Format: `{tissue}{batch}_{treatment}_{fraction}_R{replicate}` — e.g. `OE1_PB_neg_R2`.

| Token | Meaning |
|---|---|
| `OE1` / `OE2` | olfactory epithelium batch 1 (`1-27-*` files) / batch 2 (`5-22-*` files) |
| `SC` | spinal cord (single batch) |
| `PB` | photobleached |
| `NPB` | non-photobleached control — raw filenames use the legacy prefix `BY` |
| `pos` / `neg` | sorted fractions: non-bleached cells / cells the photobleached signal shifts into |
| `R1`–`R3` | replicate |

The raw-filename → sample-label map is `FILE_MAPPING` at the top of each script.

## The UMAP panel

`src/oe_analysis.py` deliberately does **not** draw a UMAP, so rerunning the pipeline leaves
the published panel intact. `UMAP_OE.*` was generated by `src/umap_tuning.py` with:

```bash
python src/umap_tuning.py --n_neighbors 3 --min_dist 0.1 --metric correlation \
    --leiden_resolution 4.0 --leiden_neighbors 3 --random_state 12 \
    --repulsion_strength 3.05 --spread 2.1
```

`src/umap_tuning_large.py` takes the same arguments and wrote `UMAP_OE_large.*`.

`src/spine_analysis.py` does draw the SC UMAP itself, from a pinned embedding (below).

## Pinned outputs

Two steps are not reproducible on their own, so the published answer is stored in `results/`
and reused. **Delete the file to recompute that step from scratch.**

| File | Why it is pinned |
|---|---|
| `results/spinal_cord/tables/UMAP_SC_embedding.csv` | UMAP on 4 points with `n_neighbors=2` is degenerate. Fresh processes settle on one of ~3 different layouts; `random_state`, `np.random.seed`, `NUMBA_NUM_THREADS=1` and `PYTHONHASHSEED` all fail to fix it. The 17-sample OE embedding *is* bit-for-bit reproducible — this affects SC only. |
| `results/*/tables/GO_Enrichment_*_table.csv` | g:Profiler is a live service and its annotation database moves — the same query returned 207 OE terms in May 2026 and 203 today. The figures are drawn from the stored tables, so a rerun needs no network. |

## Analysis parameters of record

- **NSAF** — `SAF = Total Spectral Count / Length`, then `NSAF = SAF / sum(SAF)` per run over
  `Organism == "Danio rerio"` rows, summed per gene symbol. Matrices: 1,343 genes × 17 OE
  samples, 214 × 4 for SC. Log10 transformed, then z-scored per gene.
- **PB-neg enriched set** — genes with NSAF > 0 in ≥ 3 of the 6 OE `PB_neg` samples:
  **258 genes**. This is the GO enrichment query — an experimental definition, not the
  `olfactory_genes.xlsx` marker list.
- **Marker overlap** — 51 of the 1,177 olfactory symbols are detected in the OE proteome.
  SC: 7 of 1,462 `All Genes_List` symbols, 2 of the 256 in `3-6 dpf_List`.
- **GO enrichment** — g:Profiler, organism `drerio`, FDR < 0.05, no custom background.
  207 significant terms for OE (258-gene query), 80 for SC (81-gene query). Gene symbols must
  be lower-cased — mixed case returns zero significant terms.
- **UMAP** — proteins detected in ≥ 3 samples. Script defaults are `n_neighbors=4`,
  `min_dist=0.1`, `metric=correlation`, `random_state=42`; the published panel uses the tuned
  arguments above. Leiden runs on the 2-D embedding, not on protein-space distances, so the
  clusters describe the picture rather than being independent evidence for it.
- **Heatmaps** — top 60 most variable proteins, row z-scores, hierarchical clustering on both
  axes; k-means gene clustering (k=50 for OE, k=20 for SC) for the all-protein panels.

## Caveats

- **SC has one run per condition.** The SC correlation and UMAP panels describe 4 points —
  they are descriptive, not statistical, and the SC UMAP carries no cluster structure.
- **Only one OE search is in this repository.** The same 17 raw runs were searched a second
  time outside this repo. It quantifies them near-identically (Spearman ρ 0.93–0.98 per run on
  NSAF for shared symbols) but uses modern ZFIN symbols where this search still has `zgc:` /
  `si:` / legacy names, so marker overlap differs sharply — 51 olfactory markers detected here
  versus 113 there. Every figure of record came from the search kept here. Its filenames are
  identical, so if the other search is ever brought back, keep it in a separate folder and join
  on `Protein ID`, never on `Gene`. Full comparison in `data/README.md`.
- **The `_LABEL_*` overrides** in the UMAP scripts are hand-tuned to this embedding. They are
  correct for `data/oe_proteomics/` and meaningless for anything else — clear them if the data
  or the UMAP parameters change.
- **Differential abundance** (Welch t-test on log NSAF, Benjamini-Hochberg correction) was run
  in notebooks that are not in this repository. Nothing in `results/` or `manuscript/` depends
  on them — every committed panel comes from a script in `src/`.
